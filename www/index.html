数据备份

数据只存在这台设备上，换机或清浏览器数据前，先导出备份文件。

桌面小组件

长按桌面空白处 → 小组件 → 找「猪猪称 · 记一斤」拖到桌面。先打开一次 App 记一笔，小组件上就会出现当前体重，以及 -1 / -0.1 / 记一次 / +0.1 / +1 五个按钮。点一下就直接记好，不用打开 App，下次进来会自动合并进记录。

装到桌面

安卓 Chrome：菜单 → 安装应用 / 添加到主屏幕。iPhone Safari：分享 → 添加到主屏幕。之后从桌面图标点开，直接就是数字键盘，按一下就能记。

想要更短的路径：把 quick.html 也添加到主屏幕，桌面会多一个「快速记一斤」图标，点它只出一个键盘。
